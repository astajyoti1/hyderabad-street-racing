# Hyderabad Street Racing

A browser 3D racing game set on five Hyderabad routes: Necklace Road, Charminar Old City, Hitec City, Golconda and the Outer Ring Road.

## Play

**Play it in your browser: [Hyderabad Street Racing](https://astajyoti1.github.io/hyderabad-street-racing/)**

To run it locally, open `index.html` in a modern browser (needs internet once, to load three.js r128 and fonts from a CDN). No build step.

## Controls

- Arrow keys or WASD: drive
- Space: handbrake
- Shift: nitro
- C: camera, H: horn, R: reset to road, P: pause

Finish in the top three to unlock the next route and the next car. Progress is saved in the browser.
